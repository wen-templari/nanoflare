# Archived WFP experiments

These experiments and their recorded results explain historical architecture
decisions. They are retained for reproducibility and are not part of the current
acceptance workflow. Recorded results describe their original runtime versions;
moving the harnesses does not requalify those results.

- [Loader feasibility PoC](wfp-poc/README.md): native props/RPC, capability
  boundaries and early runtime limitations.
- [Isolation PoC](wfp-isolation-poc/README.md): bounded execution, process
  containment and bridge lifecycle experiments.

Use the [official upstream examples](../wfp-examples/README.md) for current
application acceptance. Use the [client flows](../wfp-client-flows/README.md) and
[qualification checks](../wfp-qualification/README.md) for their additional
protocol, storage, recovery and capacity coverage.

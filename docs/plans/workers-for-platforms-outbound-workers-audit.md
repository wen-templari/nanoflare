Full CPU interruption and untrusted isolation are broader WFP dependencies. Durable
Object and mTLS exclusion boundaries must remain explicit until those underlying
platform capabilities exist. Neither dependency is evidence for weakening the
supported ordinary Worker target contract.

## Remaining external verification and deployment policies

No WFP-entitled account was available. Hosted selection timing, parameter
precedence/non-JSON capability transport, detailed lifetime/side-effect behavior
and dashboard equivalence remain unverified. The optional hosted comparison
backend reports actual compared case IDs and leaves absent observations
`not-compared`; its current baseline must not be described as a complete hosted
matrix. Expanding and running that comparison remains follow-up qualification
when entitlement is available.

Finite JSON parameters and their explicit size/depth/name bounds, reserved-name
and collision rejection, same-organization target ownership, admission-time target
and secret pinning, and bounded root lifetimes are documented local policies.
They are not claimed as undocumented Cloudflare guarantees. Production load and
cold-start performance are not qualified; anonymous request descriptors preserve
isolation without promising warm-isolate reuse. Cache has no backend on the
qualified executor; ordinary/outbound probes match that behavior. CPU interruption,
untrusted isolation, Durable Objects and mTLS remain underlying platform work.

The changes are prepared for review; release publication remains separate. All temporary browser/API
preview processes were cleaned up. The disposable PostgreSQL test server is
stopped after final qualification; pinned tool installations and versioned reports
remain available for reproduction.
